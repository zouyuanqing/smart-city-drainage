# must be provisioned as a verified external executable, not a pip wrapper.
#
# This is the full profile and is not the Windows fallback: it includes the
# optional AI/CUDA stack. Use requirements-hydraulic.txt on a Windows host that
# needs only API/configuration plus the pure-Python hydraulic path.
#
# Interpreter matrix (no line below may fall back to a source build):
#   * Python 3.11 is the contract interpreter: Docker, CI and the
#     requirements-py311-gpu.lock hash lock install exactly these pins.
#   * Python >= 3.13 (host tooling, e.g. Windows 3.13/3.14) installs the
#     marker-guarded companion pins that publish cp313/cp314 wheels, and skips
#     the CUDA/YOLO stack, which has no wheel for those interpreters. The API
#     and the pure-Python hydraulic path stay fully functional.
# Keep every compiler-backed dependency behind an explicit marker: an unmarked
# pin without a wheel makes `pip install` reach for pg_config / a C toolchain.
