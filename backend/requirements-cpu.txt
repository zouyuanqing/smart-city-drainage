# Smart City Drainage backend — reproducible CPU profile.
# The pure-Python hydraulic fallback is included. EPA SWMM is an optional
# external executable and is intentionally not a PyPI/native dependency.
#
# This profile is for CPU deployments and may install wheel-backed AI packages
# on Python 3.11. It is not the smallest fallback; use requirements-hydraulic.txt
# when a Windows install must avoid CUDA, Torch, OpenCV and ONNX Runtime.
#
# Interpreter matrix (no line below may fall back to a source build):
#   * Python 3.11 is the contract interpreter: Docker, CI and the
#     requirements-py311.lock hash lock install exactly these pins.
#   * Python >= 3.13 (host tooling, e.g. Windows 3.13/3.14) installs the
#     marker-guarded companion pins that publish cp313/cp314 wheels, and skips
#     the YOLO stack, which has no wheel for those interpreters. The API and the
#     pure-Python hydraulic path stay fully functional; only YOLO inference is
#     unavailable there.
# Keep every compiler-backed dependency behind an explicit marker: an unmarked
# pin without a wheel makes `pip install` reach for pg_config / a C toolchain.
